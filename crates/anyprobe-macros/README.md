# anyprobe-macros

The procedural macros of [anyprobe](https://crates.io/crates/anyprobe):
`probes!` and `#[probe]`. Depend on `anyprobe` and use them from there. The
code they generate calls into `anyprobe`, and each release of this crate
works only with the `anyprobe` release of the same version.
